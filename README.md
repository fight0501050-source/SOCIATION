# 互動白板：原住民族的傳統信仰與生活

國小社會第 1 課「信仰與生活」活動一的互動電子白板網頁。

## 檔案
- `index.html`：網頁主檔
- `images/`：網頁使用的 8 張圖片（要換照片時，用相同檔名覆蓋即可）

## 用 GitHub Pages 上架
1. 在 GitHub 建立新的 repository（例如 `social-whiteboard`），選 Public。
2. 把 `index.html` 和 `images` 資料夾上傳到 repository 根目錄。
3. 進入 Settings → Pages，Source 選 Deploy from a branch，Branch 選 `main`、資料夾選 `/ (root)`，按 Save。
4. 等 1 到 2 分鐘，網址會是 `https://你的帳號.github.io/repository名稱/`。

## 注意
網頁需要連網才能載入圓體字（Google Fonts）；沒連網時會改用系統字體，功能不受影響。
